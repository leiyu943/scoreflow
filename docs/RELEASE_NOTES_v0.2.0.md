# 谱音 ScoreFlow v0.2.0 预览版


谱音 ScoreFlow 是一个把多页吉他乐谱转成完整 MIDI 的本地桌面工具。界面使用 Electron，Python 仅运行后台识别。

### 主要功能

- 支持五线谱、纯六线谱和混合谱页；五线谱链路已做专项调整与校正，六线谱持续优化。
- 一次导入多张图片，调整页序、追加谱页，逐页识别后连接成整曲。
- 整曲 MIDI 音符卷帘、点击谱面定位播放、连续播放自动翻页。
- 7 种采样音色，调速保持音高，可导出写入所选 GM 音色的 MIDI。
- 自动保存完整 MIDI；结构兼容时可导出合并 MusicXML。
- 取消、重排和追加后，在当前曲目中复用已完成且输入/设置未变化的页。

### 下载说明

本次按**源码目录**发布，不捆绑模型权重、完整推理依赖或采样音色。先按 README 安装 Node.js、Python 3.12 和 NVIDIA 驱动，再双击“安装识别环境.cmd”，完成后双击“启动谱音.cmd”。依赖、模型和音色从固定上游地址下载到独立运行目录；源码中只记录版本、安装入口和校验清单。

公开安装默认使用 Tabbox 官方六线谱模型与配套代码。原标注器本地调整版可以另行配置，两者分别记录版本与哈希。五线谱沿用 HOMR 465 FP16 和本项目的校正规则。

完整配置后的识别需要 Windows x64、NVIDIA CUDA 显卡与兼容驱动。已在 RTX 3070 8 GB 上验证；启动时约需 5.5 GiB 空闲显存。完整运行目录约 7.13 GiB。

### 验证与边界

通过 10 项 JavaScript 单元测试、3 项 Python 导出测试、8 项跨页合并测试及 41 项打包后桌面检查。三页集成样例合成 94 个音符、88 拍，核对了整曲 MIDI 的起点与结束时间；这不是通用识别准确率。

当前没有 PDF 导入、音符编辑、CPU 识别或项目恢复；整曲采用第一页的统一速度。六线谱落点为近似位置，识别结果建议试听核对。
